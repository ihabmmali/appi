# Appi Kodi Add-on

Appi is a Kodi video add-on for user-configured movie and TV-show M3U catalogues.

## Direct install

Add `https://ihabmmali.github.io/appi/` in Kodi File Manager, then install the current `plugin.video.appi-<version>.zip`.

## 0.6.0

- Fixed-size paging for Movies, TV Shows and search results.
- Recently added and oldest-added sorting based on provider M3U order.
- Long-hold playback options for per-title/per-show HLS quality and subtitle behavior.
- Recently Played Movies with resume positions.
- Recently Played TV Shows with a Continue/Resume entry plus normal season browsing.
- Existing indexed TV catalogue, MP4 buffering controls and persistent subtitles retained.
